## 这是什么

这不是把 2D 贪吃蛇换了个 3D 皮。场地是一个 **88×88×88 的虚空立方**：鼠标控制航向与俯仰，蛇可以在任意 XYZ 位置游动，同时拖出一条完整的三维身体。

在飞行、吞噬、避开自己的尾迹和虚空威胁的同时，你会经历：

- **肉鸽构筑**：每升一级，从三张神经突变卡中选一张。共 24 张卡，分为常规 / 稀有 / 传说 / 诅咒四档。
- **主动技能**：相位折跃、湮灭脉冲、时间琥珀、超载协议。
- **增量养成**：纳米尘、机库永久强化、在线/离线数据农场。死亡带来的是永久变强，而不是归零。

## 操作

| 输入 | 动作 |
| --- | --- |
| 鼠标移动 | 航向 / 俯仰，控制完整 XYZ 方向 |
| `W` / `S` | 加速 / 制动 |
| `A` / `D` 或 `←` / `→` | 辅助左右转向 |
| `↑` / `↓` | 辅助俯仰 |
| `Space` | 相位折跃：瞬移并粉碎路径上的威胁 |
| `Q` | 湮灭脉冲：清除周围弹幕、雷区和猎手 |
| `E` | 时间琥珀：减速世界，自己保持相对高速 |
| `R` | 超载：同步率 100% 后启动 |
| `1` / `2` / `3` | 升级时选择突变卡 |
| `R`（升级界面） | 重掷突变卡 |
| `Esc` | 暂停 |
| `M` | 静音 / 取消静音 |

开始后会自动锁定鼠标。若浏览器拦截，按住鼠标左键拖动也能转向。

## 系统深度

### 24 张神经突变

- 超频线圈 / 引力奇点 / 量子护盾 / 纳米修复
- 复利算法 / 贪婪回路 / 矢量引擎 / 湮灭扩容
- 连锁共振 / 轨道哨兵 / 时滞晶格 / 猎杀协议
- 熵减引擎 / 折跃余波 / 千兆鞭尾 / 破盾新星
- 自动脉冲 / 概率窃取 / 奇点引擎 / 濒死协议
- 时间债 / 玻璃大炮 / 噬星胃袋 / 相位压缩

### 9 种永久强化 + 数据农场

护甲、推进器、拾取范围、冷却压缩、概率窃取、机魂备份……以及最重要的 **数据农场**：它会在线、离线持续生产纳米尘（离线最多累计 8 小时），让每一段等待都变成下一局的启动资金。

### 战场

数据风暴、虚空雷区、猎手哨兵、精英哨兵、追踪弹幕、边界力场。威胁会随时间升级；自己的尾巴同样致命。

## 视觉与音频

- 手写后期管线：Bloom、ACES、径向色差、扫描线、胶片颗粒、暗角、速度线、受伤/慢动作/超载分级
- 自定义霓虹着色器与 `InstancedMesh` 蛇身，整条蛇一次 draw call
- 对象池化粒子、闪电、冲击波、追踪弹幕与无人机
- 3D 雷达、坐标、高度计、俯仰仪与投影浮字
- WebAudio 程序化生成的暗黑 Synthwave 与环境音效

**无外部资源、无网络请求；所有进度存在浏览器 `localStorage`。**

## 本地运行

```bash
# 直接打开 index.html 即可；或起一个静态服务器：
python -m http.server 8000
# http://127.0.0.1:8000/
```

## 构建

```text
index.html       # 构建产物（Three.js + CSS + Game 全部内联）
template.html    # HTML 页面骨架
build.py         # 构建脚本
src/game.js      # 游戏逻辑 / 场景 / 特效
src/style.css    # HUD / 标题页 / 卡牌 / 机库
vendor/three.min.js
```

```bash
python build.py
```
